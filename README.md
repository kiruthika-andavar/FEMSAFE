FemSafe Website
A responsive project website for the FemSafe smart safety glove concept.
Files
index.html — page structure and content
style.css — responsive layout and styling
script.js — mobile navigation and dynamic footer year
Run locally
Open index.html in a web browser. No build tools are required.
Publish with GitHub Pages
Create a GitHub repository named femsafe-website.
Upload index.html, style.css, script.js, and README.md to the repository root.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and / (root), then save.
Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.
Before submission
Replace your-email@example.com in index.html with your project email.
Add your real project photos if available.
Confirm the page matches your prototype and report.
Important note
This is an informational website for a student project concept. It does not actually send SOS alerts, access GPS, or contact emergency services. Those functions require a separately developed and tested hardware/software system.
